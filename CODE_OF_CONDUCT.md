# Cod de conduită

Proiectul urmează [Contributor Covenant 2.1](https://www.contributor-covenant.org/ro/version/2/1/code_of_conduct/).

Pe scurt: discutăm despre date, reguli și cod, nu despre persoane. Nu tolerăm hărțuirea, atacurile
la persoană sau publicarea de date private.

Un lucru specific acestui proiect: nu folosi issue-urile, discuțiile sau pull request-urile ca să
acuzi o persoană sau o firmă. Un semnal este un indicator de verificat. Cine vrea să sesizeze o
faptă se adresează instituțiilor abilitate.

Abaterile se raportează întreținătorului, în privat, prin fila Security a repo-ului.
